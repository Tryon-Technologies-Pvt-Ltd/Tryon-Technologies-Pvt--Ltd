# Tryon Technologies Pvt. Ltd. — Website Release

This is the upgraded multi-page static website. It preserves the existing company content and adds new product, security, resources and portfolio content while modernising the presentation.

## Open locally
1. Extract the complete ZIP file.
2. Keep `index.html`, all other `.html` pages and the `assets` folder together in the same directory.
3. Open `index.html` in a browser.
4. Use the top navigation to open separate pages. Each main page has its own HTML file (for example `products.html`, `services.html`, `contact.html`).

## Publish online
Upload the entire extracted folder to your hosting public directory (for example `public_html`). Do not upload only `index.html`; the `assets` folder and all HTML pages are required. Static hosting such as Netlify, GitHub Pages or standard cPanel hosting can serve this site.

## Included
- 34 separately addressable HTML pages (20 main/company/service pages + 14 individual product detail pages)
- Shared CSS and JavaScript under `assets/css` and `assets/js`
- Original Tryon T-shaped logo asset
- Product and service imagery, founder portrait (shown only on the Founder profile)
- Blue/dark and white/light theme toggle
- Responsive navigation, reveal animations and hero video background
- Product catalogue search and category filters
- 14 individual product detail pages with applications, selection checks and integration notes
- Language selector (Google Translate requires internet access)
- Enquiry form that opens the visitor's email application (no server-side form storage)
- FAQ helper (not a staffed live chat)

## Before going live
- Configure the company's WhatsApp number in `assets/js/tryon.js` by replacing the empty `WHATSAPP_NUMBER` value with the international-format digits only.
- For direct online form submissions, connect a secure form backend; the current form prepares an email in the visitor's mail application.
- The hero video uses a remote Pexels MP4 source; an internet connection is required for the moving background. The bundled control-room image is the fallback poster.
- Add the final public domain to the page canonical URLs and generate an absolute-URL sitemap before SEO launch.
- Portfolio categories 02–10 are illustrative presentation entries, not independently verified client case studies. Only Mahadev Plywood is named as a confirmed client project in the supplied information. Replace illustrative visuals with approved project photographs before public launch.
- Product names shown are Tryon catalogue presentation names; actual make/model, specifications, compatibility, stock and pricing must be confirmed for each enquiry.
